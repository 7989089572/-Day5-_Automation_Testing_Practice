# 📘 Day 5 – Automation Testing Notes

Today I learned the fundamentals of **Automation Testing** and its related concepts.  
Below are my notes with definitions, real-world examples, and popular tools.

---

## 1️⃣ Introduction to Automation
**Definition:**  
Automation testing uses scripts and tools to execute test cases automatically instead of manual execution. It saves time, improves accuracy, and helps in continuous testing.

**Real-World Example:**  
Using a **washing machine** instead of washing clothes by hand. It reduces human effort, saves time, and ensures consistent results.

---

## 2️⃣ Test Scripting Languages
**Definition:**  
Test scripts are written in programming/scripting languages to automate testing processes.

**Popular Languages:**  
- **Python** – Easy to learn, popular for Selenium & PyTest.  
- **Java** – Widely used for Selenium, TestNG, JUnit.  
- **JavaScript** – Cypress, Playwright, Puppeteer.  
- **C#** – NUnit, SpecFlow for .NET applications.  

**Real-World Example:**  
Like **choosing a language** to write a recipe: English, Telugu, or Hindi. The recipe (script) stays the same, but the language used depends on the audience (tool/platform).

---

## 3️⃣ Automation Framework Selection
**Definition:**  
A framework is a structured set of guidelines and practices to create and execute automated test scripts efficiently.

**Types of Frameworks:**  
- **Linear Framework** – Simple, record & playback.  
- **Modular Framework** – Tests divided into modules for reusability.  
- **Data-Driven Framework** – Test cases driven by external data (Excel, CSV).  
- **Keyword-Driven Framework** – Keywords define actions (login, click, enter).  
- **Hybrid Framework** – Combines data-driven + keyword-driven.  

**Real-World Example:**  
Building **IKEA furniture**:  
- Step-by-step instructions (linear)  
- Separate parts for reusability (modular)  
- Different sizes/colors from the same instructions (data-driven)  
- Keywords like *“tighten screw”* or *“attach leg”* (keyword-driven)  
- A mix of all approaches (hybrid).  

---

## 4️⃣ Continuous Integration (CI) Tools
**Definition:**  
Continuous Integration (CI) tools automatically build, test, and deploy applications whenever code changes are made. CI ensures bugs are caught early and integration runs smoothly.

**Popular CI Tools:**  
- **Jenkins** – Open-source automation server.  
- **GitHub Actions** – Built-in CI/CD for GitHub projects.  
- **GitLab CI/CD** – Automation pipelines in GitLab.  
- **CircleCI / Travis CI** – Cloud-based CI platforms.  

**Real-World Example:**  
Imagine a **team of chefs** in a large kitchen:  
- Each chef adds a new recipe (code commit).  
- The CI tool checks ingredients (tests).  
- Cooks a sample dish (build).  
- Serves it automatically (deployment).  
This ensures consistent dishes (software) every time.  

---

## ✅ Summary
- Automation reduces manual effort and improves efficiency.  
- Test scripts can be written in languages like Python, Java, JS, and C#.  
- Frameworks help organize and reuse tests effectively.  
- CI tools like Jenkins and GitHub Actions ensure smooth delivery pipelines.
